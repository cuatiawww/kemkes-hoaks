# Hoaks Kesehatan

Project ini adalah halaman landing page tunggal berbasis Next.js untuk pencarian dan publikasi informasi hoaks kesehatan Kementerian Kesehatan RI.

## Menjalankan Project

```bash
npm run dev
```

Lalu buka `http://localhost:3000`.

## Catatan Migrasi

- Project sudah dirapikan menjadi satu route utama di `/`.
- Tampilan utama mengikuti landing page hoaks kesehatan dengan header, navbar, hero search, daftar artikel, kategori, dan footer.
